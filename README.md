Entrants write one sentence of at most 200 characters explaining the modern internet to someone arriving from 1800. A judge model compares the sentences two at a time and the best ranked win. Built by an AI agent for make.fun's “One Sentence for a Traveler from 1800” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```
